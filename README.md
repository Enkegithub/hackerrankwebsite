⚙️ Installation & Setup

1️⃣ Clone the Repository
git clone https://github.com/your-username/hacker-rank-club-gnit.git
cd hacker-rank-club-gnit    
2️⃣ Install Dependencies
npm install

3️⃣ Run Development Server
npm run dev

http://localhost:3000
